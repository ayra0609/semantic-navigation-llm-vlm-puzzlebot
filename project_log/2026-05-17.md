# 2026-05-17

## Development Work

### Modules Implemented / Updated

**LLM — `llm/intent_extraction.py`**
- Refactored into three-layer architecture: `_regex_extract()` / `_ollama_extract()` / public `extract_navigation_intent()`
- Added regex fallback so the pipeline continues when Ollama is unavailable
- Added structured debug logging (`[LLM]` prefix) throughout

**ROS2 Navigation Node — `ros2/navigation_node.py`**
- Fully implemented from placeholder; runs on Jetson Nano
- `PidController` class: PID angular steering (Kp=0.003, Ti=1.0, Td=0)
- `NavigationNode` class:
  - Phase 1: pure rotation to align target within ±40 px of frame centre
  - Phase 2: forward motion (0.15 m/s) with gentle PID correction
  - LiDAR safety stop at 0.40 m
  - Search rotation (0.3 rad/s) when target not detected
  - Odometry-based travel distance logging on navigation end

**ROS2 Pipeline Node — `ros2/pipeline_node.py`** *(new file)*
- Dual-mode PC-side node: `sim_mode=True` for Gazebo, `sim_mode=False` for real PuzzleBot
- Integrates LLM intent extraction + Grounding DINO VLM + visual servo in one ROS2 node
- HSV fallback detection for coloured simulation targets
- Distance estimation from bounding box (focal length model, stop at 0.50 m)
- Publishes status to `/puzzlebot/status` for Web UI feedback

**VLM — `vlm/grounding_dino.py`**
- Lowered detection confidence threshold: 0.30 → 0.25 (improves recall for distant/partially occluded objects)

**Tests — `tests/test_intent.py`**
- Fully implemented ALFRED evaluation framework from placeholder
- Loads `GotoLocation` steps from `traj_data.json`, filters by GT label presence in instruction
- Lenient match rule: exact OR substring containment (articles stripped)
- Saves detailed per-sample log to `test_log/alfred_<split>_<timestamp>.log`
- CLI: `--alfred-path`, `--split`, `--max-cases`, `--regex-only`

**Tests — `tests/test_vlm.py`** *(new file)*
- COCO 2017 val set evaluation for Grounding DINO
- Per-category accuracy breakdown; saves log to `test_log/coco_val2017_<timestamp>.log`
